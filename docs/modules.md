# Modules

The recovered integration includes:

- `compas_rhino.conversions`: Convert geometry between COMPAS and Rhino.
- `compas_rhino.geometry`: Rhino-backed curves, surfaces, Breps, and geometry operations.
- `compas_rhino.scene`: Draw COMPAS geometry and datastructures in Rhino.
- `compas_rhino.conduits`: Display geometry through Rhino display conduits.
- `compas_rhino.drawing`: Low-level drawing helpers.
- `compas_rhino.objects`: Rhino document object utilities.
- `compas_rhino.layers`: Layer management.
- `compas_rhino.install`: Historical host installation helpers.

Host modules require the corresponding application APIs. Source docstrings and
the archived COMPAS API pages remain available in the repository. Automated API
rendering is deferred until the host imports and docstrings are migrated.
