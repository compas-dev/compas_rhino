# compas_rhino

Rhino integration for the COMPAS framework.

This standalone project recovers the integration immediately before its removal
from COMPAS. The current baseline is version 2.15.0; COMPAS 3.x migration is pending.

See [Installation](installation.md), the [module guide](modules.md), and
[history and migration](history.md). Historical host guides and API reference
sources are retained in `archive/compas-docs` in the repository.
